PRESSSACK OPEN – WEBANMELDUNG

Enthalten:
- index.html: Anmeldung
- meldeliste.html: öffentliche Meldeliste
- admin.html: geschützte Verwaltung
- setup.html: erstellt die config.js ohne Texteditor
- config.js: Supabase-Verbindung
- style.css und JavaScript-Dateien

EINRICHTUNG:
1. ZIP entpacken.
2. setup.html doppelt anklicken.
3. Supabase Publishable Key einfügen.
4. "Fertige config.js herunterladen" anklicken.
5. Die neue config.js in diesen Ordner kopieren und die vorhandene ersetzen.
6. Alle Dateien in das GitHub-Repository presssack-anmeldung hochladen.
7. Auf der TSV-Webseite nur einen Link zur GitHub-Pages-Adresse setzen.

WICHTIG:
Nur den Publishable Key verwenden. Niemals den Secret Key.
